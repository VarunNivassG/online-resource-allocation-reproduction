# Reference

Primary source used for this reproduction:

Jingruo Sun, Wenzhi Gao, Ellen Vitercik, Yinyu Ye. **Wait-Less Offline Tuning and Re-solving for Online Decision Making.** Proceedings of the 42nd International Conference on Machine Learning (ICML 2025), PMLR 267. arXiv:2412.09594v3.

The supplied paper's main theoretical result is the spectrum bound

\[
\Delta_T=O\left(\log(T/f)+\sqrt f\right),
\]

with LP re-solving interval \(f\), and the principal experiments use uniform and normal synthetic inputs, frequency settings based on \(T^{1/3},T^{1/2},T^{2/3}\), and a five-resource baseline comparison.
